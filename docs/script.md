# 7-minute presentation script

Target: 6:30 spoken, 30 s buffer. One speaker at a time; slides advance on cue.

## 0:00–0:30 — Hook (Arseniy)
> "Every week a new model ships. But the model is not the product anymore — the agent is. An agent reads your repo, runs the tests, opens a browser and checks the result. Our course teaches that loop."

Cue: slide 1 (title).

## 0:30–2:20 — Audience, needs, goals (Denis)
> "We built Vibe Coding for 2nd–4th year IT students and juniors with up to two years of experience. They already write code and already use AI — chaotically. Employers expect AI literacy; juniors need to prompt well, verify generated code and avoid security and licensing traps. By the end of the course a student can write a spec, run an agentic loop in OpenCode, review AI code, debug with tests and ship one vertical slice."

Cue: slides 3–4.

## 2:20–4:05 — Curriculum and schedule (Danik)
> "Six modules, 36 hours. We start with how LLMs actually work, then prompt engineering, then the agentic workflow in OpenCode — including browser agents with Playwright. Module four is review: correctness, security, licenses, supply chain. Module five is debugging and docs. Module six is the capstone: one vertical slice, shipped and reviewed. Two live 90-minute sessions a week, blended, groups of 12–16."

Cue: slides 5–6.

## 4:05–5:50 — Value and price (Mukhammed)
> "Students leave with a repeatable workflow, a review checklist, a capstone repo and a demo video. The full course is $290; early bird $240 until November 3. It includes weekly code review, capstone review and a certificate co-signed by our IT faculty partner, plus a LinkedIn badge. The certificate opens the conversation; the capstone closes it."

Cue: slides 7–9.

## 5:50–6:30 — Demo and close (Arseniy)
> "Let me show the product. This is the live site: the agent demo runs a real OpenCode-style session in the browser, and the course has 19 lessons, labs and a certificate. Start the course at vibe-coding.dev."

Cue: slide 10 + live demo (optional, 20 s).

## Q&A prep
- Why OpenCode? Open-source, terminal-native, real tool loop, no vendor lock-in.
- Why Playwright? It gives the agent a browser: navigate, snapshot, click, extract — with allowlists and human confirmation.
- Is the certificate accredited? Co-signed by the faculty partner; verification link; not a state diploma.
- What if a student misses a week? Recordings + written briefs; the capstone needs the full six weeks.
